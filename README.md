# ครูออม · ผจญภัยวัดระดับภาษาอังกฤษ CEFR ป.6 (v3 ฉบับปรับง่าย เนื้อหา ป.4–ป.6)

แบบทดสอบวัดระดับภาษาอังกฤษเบื้องต้นตามกรอบ CEFR (Pre-A1 / A1 / A2) สำหรับนักเรียน ป.6 ที่จะขึ้น ม.1 · โรงเรียนปิยมิตรวิทยา อ.เชียงคำ จ.พะเยา
เป้าหมาย สพฐ.: จบ ป.6 = A1 · จบ ม.3 = A2
เว็บ: https://kruom9.github.io/kruom-cefr/

## ลักษณะข้อสอบ
- 4 ตอน × 25 ข้อ = 100 ข้อ: ไวยากรณ์ → คำศัพท์ → การอ่าน → การฟัง · เวลารวม 90 นาที
- **ปรับระดับอัตโนมัติ** ในแต่ละตอน: เริ่ม A1 · ถูก 2 ข้อติดกันขึ้น 1 ระดับ · ผิด 2 ข้อติดกันลง 1 ระดับ · ไม่มีข้อซ้ำ
- คลังข้อสอบ 160 ข้อ (ตอนละ 40: Pre-A1 12 · A1 16 · A2 12) · ไม่มีข้อ B1 ขึ้นไป
- เนื้อหาระดับ ป.4–ป.6 เท่านั้น: present simple/continuous, past simple, can/can't, there is/are, คำบุพบทพื้นฐาน, comparative · คำศัพท์ในชีวิตประจำวัน · บทอ่านสั้น บทฟังสั้นและช้า
- ผลแสดงเป็น ต่ำกว่า Pre-A1 / Pre-A1 / A1 / A2 (A2 คือระดับสูงสุดที่ชุดนี้วัดได้)
- ลงทะเบียน 4 ช่อง: ชื่อนักเรียน · ชื่อโรงเรียน (เลือกจากรายการ หรือ "อื่น ๆ" แล้วพิมพ์) · ชั้น · LINE ID · **ไม่เก็บเลขบัตรประชาชน**
