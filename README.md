# ครูออม · แบบทดสอบวัดระดับภาษาอังกฤษ CEFR (A1–C2)
โรงเรียนปิยมิตรวิทยา อ.เชียงคำ จ.พะเยา · เปิดใช้: https://kruom9.github.io/kruom-cefr/

- 60 ข้อ (ระดับละ 10 ข้อ A1–C2) · 60 นาที · ตรวจและแปลผลอัตโนมัติทันทีเมื่อส่ง
- ผลที่ได้: ระดับ CEFR รวม · คะแนนรายระดับ · ระดับรายด้าน 4 ด้าน (คำศัพท์ ไวยากรณ์ การอ่าน ภาษาเพื่อการสื่อสาร) พร้อมจุดแข็ง/เรื่องที่ควรพัฒนา
- ลงทะเบียนพร้อมความยินยอมของผู้ปกครองตาม PDPA · ไม่เก็บเลขบัตรประชาชน · ค่าเริ่มต้นไม่ส่งข้อมูลออกนอกเครื่อง (`SAVE_URL` ว่าง)
- ข้อสอบเขียนขึ้นใหม่ตามคำอธิบายระดับ CEFR เพื่อวัดระดับเบื้องต้น ไม่ใช่ใบรับรองระดับ CEFR อย่างเป็นทางการ
